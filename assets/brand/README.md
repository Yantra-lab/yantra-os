# Yantra brand key art

Owner-supplied key art from Sanskar Balpande, received 2026-11-05.

- `yantra-mark.png`: 512 × 512 release/marketing mark, resized from the supplied 1254 × 1254 PNG.
- `yantra-os.png`: the supplied 1672 × 941 “Yantra OS — The Rebirth of Native Speed” key art, unchanged.
- `apps/desktop/brand/yantra-mark.png`: the 256 × 256 offline app-asset copy used by the desktop
  chrome. The sandbox deliberately resolves assets inside the running app's own directory.

The cool cyan and warm champagne light in this artwork is the source of the desktop Aura palette.
