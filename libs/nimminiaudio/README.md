# nimminiaudio

Clean, idiomatic Nim wrapper for miniaudio (v0.11.21, Public Domain / MIT-0).
Powers audio decoding, waveform generation, sample mixing, and 3D spatialization.

## Vendor Details
- Upstream: [mackron/miniaudio](https://github.com/mackron/miniaudio) (v0.11.21)
- License: Public Domain / MIT-0
- Build: Pinned in tools/setup.sh; built as static libminiaudio.a.

## Testing
Run tests via `bash libs/nimminiaudio/tests/run_tests.sh`.
