# nimsqlite

Clean, idiomatic Nim wrapper for SQLite (v3.53.4, Public Domain).
Powers embedded relational storage, transactions, and binary data persistence.

## Vendor Details
- Upstream: SQLite (v3.53.4) via MSYS2 `mingw-w64-x86_64-sqlite3`
- License: Public Domain
- Build: Installed via `tools/setup.sh`; links against `libsqlite3`.

## Testing
Run tests via `bash libs/nimsqlite/tests/run_tests.sh`.
