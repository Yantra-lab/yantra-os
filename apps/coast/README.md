# Infinite Coastline

A native Mandelbrot and Julia instrument inspired by [042-fractal-explorer](https://github.com/MiaAI-Lab/Claude-Opus-5.5-100-HTML-Files/blob/main/042-fractal-explorer.html). This is a Sutra app, not an image viewer: live view state generates a native SkSL escape-time shader, and the real SDL3 + Skia + Yoga engine paints it.

## What works

- Full-window **Mandelbrot** rendering with smooth escape-time colour, a 256-radius bailout, and cardioid/period-2-bulb rejection.
- A live **158 × 158 Julia lens** follows the complex coordinate under the pointer. **J** opens that seed as the main Julia view; **M** returns to the saved Mandelbrot position and magnification.
- Four cyclic, interpolated palettes: **Aurum**, **Abyss**, **Magma**, and **Pastel Dream**.
- Five real coordinate presets: Seahorse Valley, Elephant Valley, Triple Spiral, Mini-brot, and Whole Set.
- Click to dive ×2.5 at the clicked point, drag to pan, `+` / `−` buttons, Reset, arrow-key pan, number-key presets, and `R` Home.
- Coordinates, magnification, iteration ceiling, selected place, palette, seed, and mode are all read from live state.

There is deliberately **no Export button**. This app does not implement a file/export action, so the toolbar does not advertise one.

`app.wasm`: **225,927 B**, SHA-256 `19222c8e619e81dbee587973bccb76193565a3b540fecd15041d49b2d9876727`. The app was built from Atlas cells with current Sutra at wasm32/standalone/bits32. Its explicit defines were **`nimNativeAlloc` and `nimNativeIo`**. No warm-up or screenshot define was used. The native proof tools were compiled from this branch with `-d:release`. `tools/strip-wasm.py` reported `225927 -> 225927 bytes (dropped custom sections: none)`; plain and stripped outputs are byte-identical and rendered **0 changed pixels**. A forced rebuild in the fresh `@coast-forcedcold` namespace compiled in **7.459 s** (8.10 s command wall time) and reproduced the shipped module byte-for-byte; this is separate from render cost.

`app.yantra.json` was generated by `tools/os-json.py` from the actual cells in the isolated `@coast-vector` Atlas space: **31 cells, one view, zero records**.

## Rendering resolution and measured cost

The main field is **1280 × 816 = 1,044,480 pixels** on every frame; it is not an upsampled bitmap. The Julia lens is **158 × 158 = 24,964 pixels**, capped at 180 iterations. The main iteration ceiling rises with zoom: 255 at home and 720 at Seahorse.

Measurements below were made on 2026-11-05 on this Linux x86-64 machine. Each number is **wall time for the complete fresh native command**, including engine/module load, the named real input, shader compilation/rendering, layout, and PNG output (or, for pan, raw framebuffer output). It is not a claim about a single GPU draw call. `LIBGL_ALWAYS_SOFTWARE=1` was set. The common command shape was:

## Rebuild and inspect

The build lane's tools were compiled from `tools/osproof.nim`, `render/native/sutra_shot.nim`, and `render/native/drive.nim` in private scratch, using a private Postgres 18.6 database and isolated TMPDIR/XDG cache. The commands operate on this branch's source and can be repeated inside that lane:

```sh
osproof import @coast-vector coast yantra-os/apps/coast/app.nim
```

## Follow-up: actual desktop → Library → nested Coast

Verified on 2026-11-05 using the nested-AppView bootstrap from local conductor commit `81930b38`, applied only to the proof host and not copied into this app branch. No engine source is part of this follow-up change.

The desktop launched through its real **Explore apps → Library** interaction. Its generated catalog has no Coast card, so the unmodified search/address field accepted **`y:coast`**, followed by Enter. `SUTRA_CHILD_COAST=y:@coast-forcedcold/coast.Coast` explicitly registered that source-id to the private Atlas; the conductor's `childApps(a, "7")` / `attachChild` path supplied the live person, application role, interpreter, and DB grants. The desktop's `y:coast` window was not opened by bypassing AppView with a standalone child-file host.

The exact module required by this proof was preserved in that Atlas: **225,927 B / SHA-256 `19222c8e619e81dbee587973bccb76183565a3b540fecd15041d49b2d9876727`**. Recompiling the same source against the newer `lead/award-frontend` vocabulary produced a different **228,125 B / `5aeb2e03…`** module; that was measured and **not** silently substituted for the required integrated artifact. The desktop module used as parent was SHA-256 `8ee7c8a3b18120815181ccecee6ad1afca5d18f3bcbe21dbb7a1fc5a10331b4e`.

A temporary private driver derived from the conductor's `sutra_shot` was compiled from this branch with `-d:release`; it adds text input, Enter, and eight-step pointer drags to make the unmodified Library path testable. Final shots used **90 ticks** to settle the desktop's window entrance. Earlier two-tick captures were rejected because they remained mid-fade.
